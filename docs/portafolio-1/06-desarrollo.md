# 6. Desarrollo

Alcance técnico tal como aparece en el Portafolio 1.

**Escenas principales previstas:**
- Nivel de tienda de juguetes.
- Nivel de la oficina de la tienda de juguetes (probable).

**Mecánicas que deberán programarse:**
- Sistema de vida.
- Colisiones.
- Colisiones de ataques melee.
- Recuperación de vida.
- Contador de tiempo.
- Ataque sigiloso.
- Partículas.

**Elementos que requerirán scripts en C#:**
- Comportamiento de NPCs.
- Objetos de jugadores.
- Script multijugador.
- Items.
- Script global.

**Recursos que deberán integrarse al proyecto:**
- Modelos 3D con sus respectivas texturas y materiales.
- Efectos de sonido/música.

**Orden previsto para implementar las funciones principales:**
1. Script jugador
2. Script global
3. Multijugador
4. Items y powerups
5. Partículas
6. Niveles
7. HUD
8. Splash screens
