# 3. Público objetivo

Jugadores mayores de 13 años, en PC, que disfrutan partidas competitivas cortas (10-15 min) de sigilo y deducción social.

> Nota de coherencia: el tono visual de peluches convive con mecánicas de eliminación y golpes críticos a la cabeza. Se mantiene el estilo Fall Guys/ragdoll para que la violencia se lea como slapstick, no gráfica, consistente con la clasificación +13.
